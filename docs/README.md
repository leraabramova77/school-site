# Школьный портал на базе netschool.refal.kg

Пет-проект: современный мобильный дневник для учеников УВК «Рефал» и школьный портал вокруг него — с сообществом, мотивацией и полезными материалами. Без рекламы, волонтёрский проект с открытым кодом.

## Что выяснили про старый сайт

- netschool.refal.kg — это «Сетевой Город. Образование» (NetSchool) от ИРТех, версия 5.0.28346.
- Бэкенд — классический ASP (`/asp/scripts/ajaxmethods_login.asp`), фронт — jQuery 1.11, Bootstrap 3, Underscore.
- Пароль хешируется в браузере (MD5 с солью, `md5r.min.js`).
- Вход: страна → регион → город → школа → логин и пароль.
- У этой версии есть REST API `/webapi/`, через который работает официальное мобильное приложение. Через него и строим зеркало.
- Первый шаг (этап 0): войти в свой аккаунт с компьютера, открыть F12 → Network и записать реальные запросы к `/webapi/`.

## Главные решения

**Безопасность**
- Пароли нигде не храним. Токен старого сайта лежит только в зашифрованной httpOnly-cookie.
- К старому сайту ходит только наш сервер, никогда не браузер ученика.
- Секреты — только в переменных окружения Vercel. gitleaks и Push Protection защищают от утечек в Git.
- Оценки не сохраняются в базе портала и никогда не видны другим.

**Дизайн и структура**
- Mobile-first, тёмная тема, дизайн-система с утверждением через страницу `/design`.
- Внизу только 4 вкладки: «Сегодня», «Дневник», «Школа», «Расти».
- «Сегодня» — не больше 5 карточек и одно главное действие на экран.
- Тексты в формате «историй», «тропинки» вместо каталогов ссылок.
- Разделы, которыми не пользуются 2 месяца, убираем.

**Сообщество**
- Все публикации учеников проходят модерацию до выхода. Нужен взрослый куратор.
- Нет рейтингов по оценкам: очки только за вклад, соревнуются классы.
- Нет личных сообщений между пользователями.
- Инициативы имеют смысл, только если администрация пообещает отвечать на те, что наберут порог голосов.

**Запоминалка слов**
- Своё название и талисман, без логотипа, совы и шрифта Duolingo.
- Подпись: «Неофициальный фан-проект для повторения слов. Не связан с Duolingo».

**Социальная реклама («Реальная жизнь»)**
- Никаких страшилок и шок-картинок: по исследованиям они редко меняют поведение.
- Работает: разоблачение манипуляций (как кампания truth), честная математика шансов (симулятор «Кто на самом деле выигрывает?»), позитивные нормы по реальному опросу, навыки отказа, контент от самих учеников.
- Материалы утверждает школьный психолог, кнопка «Нужна помощь» всегда в один тап.
