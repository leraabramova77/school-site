# Выкладка

Постоянная ссылка для всех — **https://leraabramova77.github.io/school-site/app/**. Это страница-переход на GitHub
Pages. Она ведёт на адрес из переменной репозитория `APP_URL`. Ссылку можно добавить `?design=a|b|c`, чтобы
открыть нужный вариант оформления.

GitHub Pages умеет только раздавать файлы. Вход в netschool требует сервера: старый сайт не разрешает браузеру
обращаться к себе с чужих страниц (нет CORS), а пароль и сессия должны оставаться на сервере (ТЗ-1 §4).

## Сейчас: демо с этого компьютера (`pnpm demo`)

Это временное решение, пока нет Vercel.

| Команда | Что делает |
|---|---|
| `pnpm demo` | собирает свежий `main` в `../school-site-demo`, запускает `next start` (порт от 5100) и туннель Cloudflare, записывает адрес туннеля в `APP_URL` и обновляет Pages |
| `pnpm demo status` | показывает, что запущено и по какому адресу |
| `pnpm demo stop` | останавливает сервер и туннель |

- Туннель — бесплатный Cloudflare Quick Tunnel, без аккаунта. Программа `cloudflared` лежит в `~/bin`, скачана с
  github.com/cloudflare/cloudflared/releases, контрольная сумма сверена.
- Адрес туннеля меняется при каждом запуске, но ссылка на Pages остаётся той же: скрипт обновляет её сам.
- Компьютер должен быть включён и не засыпать. После перезагрузки нужно снова выполнить `pnpm demo`.
- `SESSION_SECRET` демо-сборки хранится в `../school-site-demo/.env.production`. Скрипт создаёт его один раз и не
  выводит, поэтому входы переживают пересборку.
- Лимит попыток входа хранится в памяти процесса, для одного сервера этого достаточно.

## Переезд на Vercel

Всё для сборки уже лежит в репозитории: `vercel.json` (pnpm 12.14.0, регион `fra1`), обычный `next build`.

1. На https://vercel.com/new войти через **Continue with GitHub**, в блоке **Import Git Repository** выбрать
   `school-site` и нажать **Import**.
2. В **Environment Variables** добавить `SESSION_SECRET`: случайную строку длиннее 32 символов. Пометить её как
   **Sensitive**, это требование ТЗ-1 §6.
3. Нажать **Deploy**. Получится адрес вида `https://school-site-….vercel.app`.
4. Перенаправить постоянную ссылку и остановить демо:
   ```sh
   gh variable set APP_URL --body https://school-site-….vercel.app
   gh workflow run pages.yml
   pnpm demo stop
   ```
5. Дальше — по чеклисту прод-запуска (задача «Прод на Vercel» в `docs/PRD.md`): Upstash для лимита попыток входа
   на нескольких экземплярах, заголовки безопасности, свой домен.

Названия кнопок сверены с документацией Vercel, мобильную версию интерфейса никто не проверял.
