# school-site — PRD

## Концепция
Неофициальный мобильный клиент школьного дневника «Сетевой Город. Образование» (netschool.refal.kg) для учеников УВК «Рефал»,
а затем школьный портал вокруг него: новости, инициативы, мотивация, английский. Некоммерческий проект с открытым кодом.

- ТЗ-1, дневник-зеркало: [`docs/01-TZ-dnevnik-zerkalo.md`](01-TZ-dnevnik-zerkalo.md).
- ТЗ-2, портал: [`docs/02-TZ-shkolnyi-portal.md`](02-TZ-shkolnyi-portal.md).
- Обзор и главные решения: [`docs/README.md`](README.md).

Порядок: сначала ТЗ-1 (этапы 0–8), потом ТЗ-2 (этапы 9–16).

## Открытые вопросы
- Где держать сервер: netschool.refal.kg не отвечает серверам Vercel (проверено 24.10.2026 из fra1, bom1, iad1 — таймаут/502/504), с домашнего интернета отвечает. Варианты — в `docs/deploy.md` → «Vercel». Пока работает демо с компьютера Леры. Капчи на входе нет (0003).
- Вход Леры 18.10.2026: `postlogin.asp` отвечает 200 и автоформой с `AT`, сессия — cookie `NSSESSIONID`, `ASPSESSIONID*`, `ESRNSec` (сутки), см. `docs/api-map.md` §1.4. Разметка ответа снята в 0013 (автоформа на `SecurityWarning.asp`). Осталось: текст ошибки неверного пароля и таймаут простоя сессии — замер прерван перезагрузкой 21.10, перезапустить (`pnpm netschool:watch`), итог записать в `docs/api-map.md` §1.4 и сюда.
- Rate limit входа: сейчас в памяти сервера (5 попыток за 10 мин с IP). На Vercel каждый экземпляр функции считает отдельно — до прод-запуска подключить Upstash (бесплатный тариф, аккаунт Леры).
- Название и логотип проекта (не должны выдавать себя за школу или ИРТех) — до запуска (задача 0034).
