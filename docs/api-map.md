# Карта API netschool.refal.kg

Разведка 18.10.2026 (задача 0003): открытые страницы через `curl`, страницы после входа — в браузере на аккаунте
ученика. Здесь только структура. Все значения (имена, оценки, id, токены) **выдуманные** или заменены на `<…>`.

## Главное

- «Сетевой Город. Образование» **5.0.28346** на IIS 7.5 + классический ASP (`X-Powered-By: ASP.NET`).
- **REST API `/webapi/` не работает.** Папка `C:\Program Files\NetSchool4\WebApi` на сервере есть, но IIS отдаёт её как
  статические файлы: `GET/POST /webapi/auth/getdata`, `/webapi/prepareloginform`, `/webapi/logindata` → 404,
  `/webapi/` → 403.14. Поэтому план из ТЗ-1 §2 (REST, как мобильное приложение и `netschoolapi`) здесь не подходит.
- Работаем как браузер: POST-формы на `.asp`-страницы, ответы — **HTML** (кодировка UTF-8), несколько AJAX-методов
  отдают JSON. Нужен разбор HTML на сервере (Zod — уже на результат разбора).
- Капчи на входе нет. Вход по логину и паролю, `LoginType=1`.
- Сессия — cookie `NSSESSIONID` и `ASPSESSIONID…` + токен `AT` (24 цифры), который передаётся полем `AT` в каждом POST.
- На старом сайте стоит Яндекс.Метрика (`mc.yandex.ru`) — в нашем клиенте её нет: к старому сайту ходит только сервер.

## Общие правила запросов

- База — `https://netschool.refal.kg`, константа в коде.
- После входа каждый запрос — `POST`, `Content-Type: application/x-www-form-urlencoded`, cookie сессии и поля:
  - `AT` — токен из ответа на вход (на страницах — скрытое поле `AT` и JS-переменная `strATTok`);
  - `VER` — любое число (сайт кладёт метку времени, служит «антикэшем»);
  - `LoginType=0` (после входа).
- Ошибка или протухшая сессия → `302` на `/asp/error.asp?…` или страница с заголовком `NetSchool. Ошибка`.
  Считать это «сессия недействительна» → удалить нашу cookie, отправить на вход.
- Даты на сайте — `d.MM.yy` (`12.10.26`, `7.09.26`), неделя начинается с понедельника.

## 1. Вход

### 1.1. Страница входа — `GET /`

Ставит cookie `NSSESSIONID`, `ASPSESSIONID…`. В HTML есть всё, что нужно для входа (берётся заново при каждом входе):

| Что | Где в HTML | Пример (выдуманный) |
|---|---|---|
| Соль | `constants.salt` в inline-скрипте: `salt: '1234567890'` | `1234567890` |
| `LT` | `<input type="hidden" name="LT" value="…">` | `123456789` |
| `VER` | `<input type="hidden" name="VER" value="…">` | `987654321` |

### 1.2. Справочник школ — `POST /asp/scripts/ajaxmethods_login.asp`

Тело: `method=InitLoginForm&login=&t=1`. Ответ — JSON (это публичные данные, их можно хранить в коде):

```json
{
  "data": {
    "countries": [{ "id": 3, "name": "Киргизия" }, { "id": 2, "name": "Россия" }], "CID": 3,
    "states": [{ "id": 88, "name": "Чуйская область" }], "SID": 88,
    "provinces": [{ "id": 1, "name": "Чуйская область" }], "PID": 1,
    "cities": [{ "id": 7, "name": "Бишкек" }], "CN": 7,
    "funcs": [{ "id": 2, "name": "Общеобразовательная" }], "SFT": 2,
    "schools": [{ "id": 13, "name": "…" }, { "id": 2, "name": "УВК \"Рефал\"" }], "SCID": 13
  },
  "message": null, "errorCode": 0, "isError": false
}
```

Смена уровня в цепочке — тот же адрес, `method=kPrepareLoginForm`, поля `CID, SID, PID, CN, SFT, SCID`,
`LASTNAME=<изменённое поле>`; ответ `{ data: { lastElem, items: [{ id, name }] } }`.

На сервере один город и одна нужная школа, поэтому на старте выбор школы можно не показывать:
**УВК «Рефал»: `CID=3, SID=88, PID=1, CN=7, SFT=2, SCID=2`**. Поиск по школам — если появятся другие.

### 1.3. Хеш пароля (`/asp/md5r.min.js` + `about.min.js`)

```
PW2 = hexMD5( salt + hexMD5(пароль) )      // hex в нижнем регистре
PW  = PW2.substr(0, длина_пароля)
```

`hexMD5_` переводит символы в коды **windows-1251** (кириллица `А–я` → `код − 848`, `Ё` → 168, `ё` → 184, `№` → 185,
прочее вне 0–255 → 0) и только потом считает MD5. На сервере повторяем эту таблицу сами (`src/shared/netschool/password.server.ts`): `iconv-lite` дал бы «?» вместо 0.

### 1.4. Вход — `POST /asp/postlogin.asp`

Поля формы (как отправляет браузер): `LoginType=1`, `CID`, `SID`, `PID`, `CN`, `SFT`, `SCID`, `UN` (логин),
`PW` (обрезанный хеш), `PW2` (полный хеш), `LT`, `VER`, `ECardID=` (пусто).

Успех — переход на `/asp/Announce/ViewAnnouncements.asp` (или другую стартовую страницу), в HTML есть `strATTok`
и скрытые поля `AT`. Точный формат ответа (302 или страница с JS-переходом) и текст ошибок «неверный пароль»
проверяется на реальном входе в задаче 0012/0015.

### 1.5. Выход — `POST /asp/logout.asp`

Поля: `AT`, `VER`. Ответ — страница с заголовком `NetSchool. Вы вышли из системы NetSchool.`

## 2. Навигация между разделами

Меню — форма `MenuForm` (`LoginType`, `AT`, `VER`, `MenuItem`, `TabItem`, `optional`), которая отправляется POST-ом
на адрес раздела. Нам меню не нужно: каждый раздел открывается прямым POST на его адрес с `AT` и `VER`.

| Раздел | Адрес |
|---|---|
| Доска объявлений (стартовая) | `/asp/Announce/ViewAnnouncements.asp` |
| Дневник (задания и отметки) | `/asp/Curriculum/Assignments.asp` |
| Расписание: день / неделя / месяц / год | `/asp/Calendar/DayViewS.asp`, `WeekViewTimeS.asp`, `MonthViewS.asp`, `/asp/SetupSchool/Calendar/YearView.asp` |
| Отчёты (список) | `/asp/Reports/Reports.asp` |
| Почта, форум, настройки | `/asp/Messages/MailBox.asp`, `/asp/Forum/Forum.asp`, `/asp/MySettings/MySettings.asp` |

## 3. Дневник — `POST /asp/Curriculum/Assignments.asp`

Заголовок страницы: `NetSchool. Дневник (1 четверть)`. Поля формы `Assignments`: `LoginType=0`, `AT`, `VER`,
`DATE=<понедельник недели>` (`12.10.26`), `PCLID_IUP=<id класса>_0` (берётся из страницы, например `10001_0`).

Выбор недели — `<select name="DATE">`: `value="12.10.26"`, текст `(12.10.26 - 18.10.26) :7` (номер недели в году).
Без `DATE` сайт отдаёт текущую неделю.

Таблица `table.table.table-bordered.table-thin.table-xs`:

| Колонка | Пример (выдуманный) |
|---|---|
| Срок сдачи | ячейка `td.hidden-scr-sm` с `rowspan` на все задания дня, ссылка `dayschedule('12.10.26')`, текст `12.10.26, Пн` |
| Предмет | `Алгебра` |
| Тип задания | код: `Д`, `З`, `С`, `О`, `К`, `_П`, `А`, `рд`, `пр`, `пд`, `ср` (расшифровка — в отчёте «Успеваемость», колонка «Тип задания», например «Домашняя работа») |
| Тема задания | ссылка `SubmAssign(<AID>,<CID>,<TP>)`, текст — тема |
| Вес | `10`, `100` |
| Отметка | `5`, `4`, … или `-` (нет отметки) |

Перед каждым днём ещё строка `tr.visible-scr-row-sm` (для мобильной вёрстки) — её пропускать. Строки заданий —
`tr[bgcolor]`.

### 3.1. Подробности задания — `POST /asp/ajax/Assignments/GetAssignmentInfo.asp`

Поля: `AID`, `CID`, `TP` (из `SubmAssign`), `PCLID_IUP`, `AT`, `VER`. Ответ JSON:

```json
{ "data": { "strTitle": "Информация о задании: …", "strTable": "<table>…</table>" },
  "message": null, "errorCode": 0, "isError": false }
```

`strTable` — строки `th`/`td`: «Домашнее задание», «Срок сдачи», «Подробности от учителя», «Присоединенный файл».
**HTML от учителя — только через санитайзер** (ТЗ-1 §4.6).

## 4. Расписание дня — `POST /asp/Calendar/DayViewS.asp`

Поле `date=13.10.26`. Заголовок: `NetSchool. Расписание уроков и мероприятий на день: вторник, 13.10.26 (1 четверть)`.
Таблица `table.schedule-table`: колонки «Время» (`8:30 - 9:10`) и «Уроки и мероприятия» (`Урок: Алгебра`).
Кабинета нет.

Неделя — `WeekViewTimeS.asp` (`DATE`, `ViewType=0|1`): компактная таблица дни × номера уроков, без времени.
Для «Сегодня» и «Дневника» время берём из `DayViewS` (один запрос на день) или из расписания звонков.

## 5. Объявления — `POST /asp/Announce/ViewAnnouncements.asp`

Форма `announcements`. Пусто — `div.alert.alert-info` с текстом-заглушкой. Разметку непустой ленты посмотреть,
когда объявления появятся (задача 0020); текст объявлений — только через санитайзер.

## 6. Отчёты (оценки)

Каждый отчёт: сначала страница-фильтр (`/asp/Reports/Report<Имя>.asp`, открывается через `GoToLink` из
`Reports.asp`), затем «Сформировать» → POST на `/asp/Reports/<Имя без Report>.asp` с полями фильтра.

| Отчёт | Фильтр → данные | Поля |
|---|---|---|
| Итоговые отметки | `ReportStudentTotalMarks.asp` → `StudentTotalMarks.asp` | `PP`, `BACK`, `ThmID=1`, `RPTID=0`, `A`, `NA`, `TA`, `RT`, `RP`, `PCLID`, `SID` (id ученика) |
| Средний балл | `ReportStudentAverageMark.asp` → `StudentAverageMark.asp` | `ThmID=1`, `RPTID=1`, … |
| Динамика среднего балла | `ReportStudentAverageMarkDyn.asp` | `ThmID=1`, `RPTID=2` |
| Отчёт об успеваемости | `ReportStudentGrades.asp` → `StudentGrades.asp` | как выше + `PCLID_IUP`, `SCLID` (id предмета, `<select>` из ~20 предметов), `ADT`/`DDT` (период `1.09.26`–`31.08.27`) |

- «Отчёт об успеваемости» — **один предмет за запрос**: таблица `table.table-print` с колонками «Тип задания»,
  «Тема задания», «Дата выполнения», «Оценка», над ней — учитель, класс, предмет, период.
- «Итоговые отметки» в середине четверти — короткая заглушка `<H3>…</H3>` без таблицы.
- Открыть фильтр отчёта прямым POST без `ThmID`/`RPTID` нельзя — `302` на `error.asp`.

**Вывод для экрана «Оценки»:** средние и распределение считать из дневника (`Assignments.asp`: отметка + вес) по
неделям четверти. Это ~9 запросов на четверть, поэтому кэш на клиенте и запрос по требованию. Итоговые отметки —
из `StudentTotalMarks.asp`, когда они выставлены.

## 7. Что ещё проверить

- Формат ответа `postlogin.asp`: успех, неверный пароль, заблокированный вход (0012, 0015).
- Сколько живёт сессия без активности (ASP обычно 20–60 мин) — для срока нашей cookie (0012).
- Отвечает ли сервер на запросы из Европы/США (функция Vercel, регион `fra1`) — после подключения Vercel.
- Расшифровка кодов типов заданий (`Д`, `К`, `_П`…) — из отчёта «Успеваемость».
- Разметка непустых объявлений и вложений.
